
# Employee Leave Management System

A simple Python-based application to manage employee leave requests.

## Features

- Apply for employee leave.
- Calculate total leave days.
- View all submitted leave requests.
- Store leave information using JSON.

## Technologies Used

- Python
- JSON
- Git
- GitHub

## How to Run

1. Clone the repository.
2. Navigate to the project directory.
3. Run the following command:

   python main.py
